Way A · any AI chat, nothing to install

  1. Unzip the folder and open paste-prompt.md.
  2. Once: run the STYLE BUILDER with 5 to 10 emails you have sent (collect-my-emails.md shows how to get them out of any email system). Keep the MY STYLE block it gives you.
  3. Each time: paste your MY STYLE block plus the whole thread into ChatGPT, Claude or Gemini, and say what you want. Free plans work.

Way B · the Claude Code skill

  1. Needs Claude Pro (USD 20/month) with Claude Code installed.
  2. Move the email-intelligence-desk folder into your skills folder: ~/.claude/skills/ on Mac, %USERPROFILE%\.claude\skills\ on Windows. Cannot see the hidden folder? Ask Claude Code to move it for you.
  3. Paste a thread and say help me reply to this. On first use it asks your permission and learns your style. connect-my-email.md explains a read-only email connection if you want one later; it never asks for your password.

The examples/ folder has four worked examples on invented data, labelled EXAMPLE. CREDITS.md names the open-source project the starting idea came from.

Honest limits
