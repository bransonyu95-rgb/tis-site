Way A · any AI chat, nothing to install

  1. Unzip the folder and open paste-prompt.md in any text editor.
  2. Pick one task you redo every week. If your company has a written SOP for it, open it too.
  3. Copy the whole box, from START to END, into a new chat in ChatGPT, Claude or Gemini. Answer one question at a time. About 30 minutes.

Way B · the Claude Code skill

  1. Needs Claude Pro (USD 20/month) with Claude Code installed.
  2. Move the waste-hunt folder into your skills folder: ~/.claude/skills/ on Mac, %USERPROFILE%\.claude\skills\ on Windows. Cannot see the hidden folder? Ask Claude Code to move it for you.
  3. Drop your SOP, a sample report or an export into sop-in/ and say waste hunt.

Honest limits
