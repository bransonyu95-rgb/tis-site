Sorted bar chart — comparing a few things

Factory use: Defects by machine, output by line, downtime by reason

Rule: Sort big-to-small; axis starts at zero

Mistake: alphabetical order — sorting IS the analysis

Pareto chart — the vital few causes

Factory use: NCR causes, downtime reasons, complaint categories — the factory classic

Rule: Sorted bars + cumulative line; talk about the first 2-3 bars only

Mistake: presenting all 14 causes with equal airtime

Bar with a target line — target vs actual

Factory use: Output vs plan, OTD vs the 95% commitment

Rule: The target line turns data into a verdict

Mistake: showing actuals with no reference — nobody knows if it's good
